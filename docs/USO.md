# Manual de uso

## Primera partida

1. En la licencia, abrí el teclado con **Cuadrado**, escribí tu nombre y confirmá con **Start**.
2. En el periódico, entrá a los clasificados y comprá un auto. El Chevrolet
   de $400 es una opción para empezar y deja $350 en la partida nueva.
3. Desde el garaje, entrá a **Bob’s Drive-In** y elegí un rival para correr.
4. En una carrera de aceleración, esperá la luz verde. Si tu auto es automático,
   pulsá **R** para ponerlo en Drive. Acelerá con **Arriba**.
5. Volvé al garaje y guardá desde el menú del juego antes de salir.

## Controles

| Botón | Acción |
|---|---|
| Cruceta o stick analógico | Mover el cursor. En carrera, arriba acelera, abajo frena e izquierda/derecha giran. |
| Cruz | Clic. En carrera acciona el cambio original. |
| Círculo | Cancelar o volver. Durante la conducción en ciudad, la salta. |
| Cuadrado | Abrir el teclado en pantalla. Permite enviar una tecla de menú o introducir texto. |
| Start | Enter. Confirma el texto del teclado en pantalla. |
| Select | Borrar un carácter en los campos de texto. |
| L / R | Bajar / subir marcha. R selecciona Drive en un auto automático. |
| Triángulo | Activar o desactivar música. |
| Start + Select | Salir del juego. |

Para hacer una copia de tus partidas y puntajes, guardá la carpeta `Save` que
está al lado del EBOOT. Volvé a colocarla en la misma ruta para restaurarla.
